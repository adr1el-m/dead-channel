# Dead Channel — documentation package

Start with **index.html** for the illustrated local preview or **Dead-Channel-Build-Dossier.pdf** for the 15-page technical guide.

## Deliverables

- FORUM-POST.md: editable, first-person element14 project draft.
- diagrams/: six editable SVG drawings and high-resolution PNG exports.
- photos/: five JPEG copies of the supplied HEIC photographs, oriented by their embedded metadata. Original HEIC files remain unchanged.
- wiring-netlist.csv and wiring-netlist.json: logical electrical connections.
- BUILD-GUIDE.md: portable setup and commissioning.
- EVIDENCE.md: claim boundaries and remaining checks.
- research/2025-BENCHMARK.md: reviewed winners, official sources and editorial rationale.
- PUBLISHING-CHECKLIST.md: media/upload finishing steps.
- validation/: current 30-test transcript and artifact checks.
- tools/: local authoring scripts; edit runtime/font paths for another machine.

The gameplay recording will be supplied later. Its link is the deliberate remaining article slot. No element14 post or competition submission has been made. Source and the browser demo are published separately through GitHub.

The 2.5D assembly map is an illustration reconstructed from the photographs. It is not a Tinkercad project, electrical simulation, or a verified map of hidden breadboard rows. Use the firmware-based atlas/netlist for connections and verify the real wiring.

Source ZIP preserves the current runnable implementation. Its serial defaults describe this prototype; use the command-line overrides in BUILD-GUIDE.md for your own units. Existing machine-specific deployment scripts and historical setup notes are deliberately not part of the source attachment.
